One can define a program class with an end and a beginning; if 2D, then another end with a wider beginning, possibly arbitrarily dimensional. Then you have a class of program and can morph this program in any direction, and it still remains the same program class. This is comparable to a program line, but the line operates with abstraction instead of the complex crystallity of a table or matrix used in a program class. This is feasible with the programming class and, if necessary, operations on it, such as all existing and conceivable arithmetic operations or analysis procedures like differentiation, differential, or integration. Both analysis and arithmetic, as morph operations of software, can be implemented much more easily as syntax-coded programming if the paradigm is already available and ready to start coding.
