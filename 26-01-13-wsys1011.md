# Umwandlung mehrerer Einheiten in Realitätswert (wahr/falsch)

Ziel: Mehrere Einheiten (z. B. Banane, Zucchini, Gurke, Schlange) sollen zu einem **Realitätswert** zusammengefasst werden:

- 1 = wahr (real)
- 0 = falsch (nicht real)

---

## 1. Kodierung der Einheiten

| Einheit   | Realitätswert (1/0) |
|-----------|--------------------|
| Banane    | 1                  |
| Zucchini  | 1                  |
| Gurke     | 1                  |
| Schlange  | 0                  |

---

## 2. Kombination von mehreren Einheiten

**Logische Operationen:**

- **AND** → nur 1, wenn alle Einheiten real sind  
  Beispiel: Banane(1), Zucchini(1), Schlange(0) → `AND = 0`
- **OR** → 1, wenn mindestens eine Einheit real ist  
  Beispiel: Banane(1), Zucchini(1), Schlange(0) → `OR = 1`

---

## 3. Mehrere Einheiten → ein Element

1. Jede Einheit bekommt ihren Realitätswert (1 oder 0)  
2. Kombinieren:  
   - **AND** → Element ist real, wenn alles real ist  
   - **OR** → Element ist real, wenn mindestens eine real ist  
3. Ergebnis: Realitätswert `1` oder `0`

---

### Beispiel: Gurke, Zucchini, Banane

| Einheit   | Realitätswert |
|-----------|---------------|
| Gurke     | 1             |
| Zucchini  | 1             |
| Banane    | 1             |

- **AND** → 1 (alles real)  
- **OR** → 1 (mindestens eine real)

### Beispiel: Gurke, Zucchini, Schlange

| Einheit   | Realitätswert |
|-----------|---------------|
| Gurke     | 1             |
| Zucchini  | 1             |
| Schlange  | 0             |

- **AND** → 0 (nicht alles real)  
- **OR** → 1 (mindestens eine real)

---

## 4. Zusammenfassung

- **Schritt 1:** Jede Einheit kodieren (1 = real, 0 = nicht real)  
- **Schritt 2:** Mehrere Einheiten kombinieren (AND / OR)  
- **Schritt 3:** Ergebnis = Realitätswert (1/0)
