# Element-Delta aus drei Einheiten

Ziel: Aus **drei Einheiten** (z. B. Gurke, Zucchini, Banane) wird ein **Element-Delta** berechnet, das das **Verhalten des Elements** beschreibt.

- Delta = Maß für Unterschied / Variation zwischen den Einheiten
- Jede Einheit kann:
  - numerisch sein → Zahlen vergleichen
  - boolesch sein → wahr/falsch vergleichen
  - kategorisch sein → Unterschiedlichkeit als Abstand codieren

---

## 1. Kodierung der drei Einheiten

| Einheit   | Wert / Kategorie |
|-----------|-----------------|
| Einheit A | z. B. Zahl 1    |
| Einheit B | z. B. Zahl 2    |
| Einheit C | z. B. Zahl 3    |

---

## 2. Delta berechnen

### 2.1 Numerisches Delta

Für Zahlen:

- Maximal-Delta: `max(Δ_AB, Δ_AC, Δ_BC)`
- Mittelwert-Delta: `(Δ_AB + Δ_AC + Δ_BC) / 3`

---

### 2.2 Boolesches Delta

Für Wahr/Falsch-Werte (1/0):

- Delta = `1`, wenn nicht alle gleich  
- Delta = `0`, wenn alle gleich  

Beispiel: `[1, 1, 0]` → Delta = 1  
Beispiel: `[1, 1, 1]` → Delta = 0

---

### 2.3 Kategorisches Delta

Für Kategorien (z. B. „Banane“, „Zucchini“, „Gurke“):

- Delta = Anzahl verschiedener Kategorien minus 1  
- Beispiel: `[Banane, Gurke, Banane]` → Delta = 1  
- Beispiel: `[Banane, Zucchini, Gurke]` → Delta = 2  

---

## 3. Element-Verhalten aus Delta ableiten

- Je größer das Delta, desto **diverser / unterschiedlicher** das Element  
- Beispiel Gewichtung für Elementwert:

- Für boolesches Element kann Delta als **Realitätsprüfung** dienen:  
  - Delta = 0 → alle gleich → Element real = 1  
  - Delta > 0 → Unterschied → Element real = 0 oder angepasst
