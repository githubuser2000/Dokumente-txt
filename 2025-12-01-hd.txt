Hier ist eine präzise, systematische und technisch saubere Übersicht darüber, welche der echten Alternativen zu Android/iOS emulierbar und virtualisierbar sind — und auf welchem Niveau.
Ich strukturiere es nach Architektur, Machbarkeit, Performance, Bottlenecks und Realwelt-Tools.
🧠 Grundprinzip (wichtig für die Einordnung)
Emulation = Hardware nachbilden
→ langsam, aber überall möglich
Virtualisierung = Hardware nativ, OS als Gast
→ schnell, aber nur wenn Kernel/Architektur kompatibel ist (ARM vs x86, Kernel-Features etc.)
iOS ist praktisch nicht emulierbar oder virtualisierbar, außer in illegalen Apple-Internals → fällt raus.
Damit bleiben:
Android-Derivate, Linux-Mobile-OS, Exoten.
1️⃣ Android / AOSP-Derivate
GrapheneOS, CalyxOS, LineageOS, AOSP, Divestos
Emulierbar? → Ja
Sehr gut über:
Android Emulator (AOSP / AVD)
Genymotion
Waydroid (Linux host → Android container)
Redroid (Android in Docker mit GPU-Passthrough)
Anbox / Anbox-Cloud
Virtualisierbar? → Teilweise
Android selbst ist nicht für klassische Virtualisierung gebaut.
Aber:
Virt-Android über QEMU (ARM → x86/ARM)
Pixel-Virtualization / crosvm-based Android (experimentell)
GVM (GrapheneOS Virtual Machines) ← sehr hochwertig
VMOS (ARM-on-ARM virtualisiert)
→ Android ist die einfachste Plattform für Emulation & teils Virtualisierung.
2️⃣ Linux-basierte Mobile-OS (echte Alternativen)
postmarketOS (Alpine Linux)
Emulierbar → Ja, exzellent
QEMU (ARM / x86)
Voller Mainline-Linux → läuft wie jede Linux-Distribution
Phosh, Sxmo, Plasma Mobile laufen sauber in VM
Virtualisierbar → Ja
KVM/QEMU
LXC/LXD
systemd-nspawn
→ PMOS ist nativ virtualisierbar, weil es echtes Linux ist.
Mobian (Debian Mobile)
Emulation: Ja (QEMU ARM64)
Virtualisierung: Ja (KVM-Linux)
→ Wie Debian, nur Mobile UI.
Ubuntu Touch (UBports)
Emulierbar
Ja, aber schwieriger.
QEMU möglich
Lomiri stack baut auf Mir/Wayland → läuft in VM, aber nicht perfekt
Virtualisierbar
→ bedingt
Android-Treibern abhängig → viele Hardware-Stacks erwarten „Android HAL“.
Für PinePhone: Ja, für Android-Basisgeräte: kaum.
PureOS Mobile (Librem 5)
Emulierbar
Ja: QEMU ARM64 Images verfügbar.
Virtualisierbar
Ja: echtes Debian → trivial.
3️⃣ Exoten / Spezialfälle
Sailfish OS (Mer, Wayland, Qt)
Emulierbar → Ja
Sailfish Emulator (offiziell)
QEMU ARM Image
Virtualisierbar → Nein / Kaum
Der Android-HAL Layer + proprietäre Komponenten machen reine VM schwierig.
KaiOS (Firefox OS)
Emulierbar → Ja
„Gonk“-basiert
Emulator über Firefox Tools
Gecko-based → leicht
Virtualisierbar → Nein
Hardware-Abhängigkeiten + Treiber.
OpenHarmony / HarmonyOS
Emulierbar → Ja
DevEco Studio Emulator
ARM emulator
Virtualisierbar → Teilweise
Mini-system images laufen in QEMU
Vollsystem mit Microkernel-LiteOS schwer
Fuchsia OS (Zircon Microkernel)
Emulierbar → Ja (offiziell)
fx emu
Fuchsia QEMU target
Virtualisierbar → Nein
Noch nicht vorgesehen.
